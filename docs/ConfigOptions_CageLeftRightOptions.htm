Configuration Options :: Cage LEFT and RIGHT SIDES Geometry & Ventilation Options

Starting with version 0.50, the open ventilation areas of cages can optionally be replaced with a configurable ventilation grid.

These settings only apply to the left and right sides of the cage proper. Separate controls are present for the top/bottom and back of the cage. These settings do not apply for cageless faceplates created by setting the faceplate only option to a fixed height.

cage left geometry
cage right geometry
new for version 0.7 :: This setting determines how CageMaker PRCG generates the sides of the cage, which can be one of the following:

  • Open <side> is the default setting, which produces a largely open side with maximum ventilation area.
  • Solid <side> (No Ventilation Cutout) produces a solid side without any opening.
  • Structure Only, Completely Open provides the maximum amount of open space while still generating a structurally strong cage.
  • No <side> At All instructs CageMaker PRCG to not generate that side.
  • The ventilation grid options select a ventilation grid with the listed hole shape.

The no <side> at all setting should only be used in rare situations as it reduces structural integrity. For most cases where maximum open space is desired, the structure only, completely open setting is a better choice.

cage sides vent hole size
This setting sets the size of the holes of the ventilation grid. Although the measurement is in mm, what precisely is measured will vary by the grid pattern, so while this will be the actual hole diameter for hole grids, it will be the major width across openings for hexagonal grids, triangle height for triangle grinds, and so on.

The sample picture at right shows a ventilated cage side panel - enabling ventilation for other cage sides and the faceplate will have similar results.

This setting affects different ventilation grid types in different ways - experiment with it to find usable results.

cage sides vent wall thickness
This setting sets the size of the solid portions between the holes of the ventilation grid. Higher values provide thicker walls but reduce the effective open area of the grid.

The sample picture at right shows a ventilated cage side panel - enabling ventilation for other cage sides and the faceplate will have similar results.

This setting affects different ventilation grid types in different ways - experiment with it to find usable results.

cage sides vent grid horizontal offset
cage sides vent grid vertical offset
These settings change the offset of the ventilation grid in each axis. By default, ventilation grids are centered on the cage wall, and these shift that center point.

The sample picture at right shows a ventilated cage side panel - enabling ventilation for other cage sides and the faceplate will have similar results.

This setting is generally cosmetic, as it does not generally have any significant effect on ventilation or structural integrity.

cage sides vent grid angle
This setting changes the angle of the ventilation grid.

The sample picture at right shows a ventilated cage side panel - enabling ventilation for other cage sides and the faceplate will have similar results.

This setting is generally cosmetic, as it does not generally have any significant effect on ventilation or structural integrity.
