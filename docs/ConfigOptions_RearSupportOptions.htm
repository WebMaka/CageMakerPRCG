Configuration Options :: Rear Support Options

Starting with version 0.50, CageMaker PRCG can generate a secondary rear-mounted "sub-cage" to help support longer/heavier devices from both front and rear.

generate rear support cage
When this setting is enabled, CageMaker PRCG will create a second "sub-cage" that inserts into the back side of a rack with tabs that slip into the rear of a front-mounted device cage. This essentially helps support the backside of a heavier device.

This is intended for use with racks that have rails on both front and rear.

This feature cannot be used in conjunction with either the split cage into two halves or the print cage separately options. Enabling either will override this option and disable generating a rear support cage.

rack total depth
CageMaker uses this setting to determine how long/tall a rear support "sub-cage" needs to be to attach to the front-mounted device rack. Set this value to the front-to-back measurement of the rack from its rails' mounting surfaces, outside-to-outside.

The total length of the rear support "sub-cage" is automatically calculated based on the total rack depth and the depth of the device.

rear support overlap
This setting determines how much a rear support "sub-rack" will extend into the rear of a front-mounted device rack.

The deeper the extension distance the better the support, but this overlapping region will block side ventilation openings on the front-mounted device cage.
