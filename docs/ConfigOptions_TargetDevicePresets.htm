Configuration Options :: Target Device Presets

The easiest custom rack generation ever - pick a device from a list and immediately get a ready-to-render basic cage for mounting that device into a 10" rack without requiring any additional work.

Selecting a device preset will automatically set the device dimensions (height, width, and depth) and override the settings for manual support cage base size and manual surface thickness in order to suit the typical needs for supporting the selected device. For some devices, cage bottom geometry will also be set to solid - this should be expected if the device has a non-flat bottom.

preconfigured device
Select a device from the list to automatically configure a cage to contain it.

Please be aware that this only presets the cage for the size, shape, and weight of the device, and other settings may need to be adjusted for best results.
